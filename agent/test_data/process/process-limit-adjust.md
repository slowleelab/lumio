# 信用卡额度调整（提额/降额）办理介绍

## 临时额度提升

**办理条件**：开卡满 3 个月、近 6 个月无逾期记录、账户状态正常。

**调整幅度**：一般为固定额度的 10%–50%，有效期最长 30 天，到期自动恢复原额度。

**办理渠道**：
1. 「发卡银行 APP」→ 额度管理 → 临时额度调整；
2. 微信公众号「发卡银行信用卡」→ 我的额度 → 额度调整；
3. 拨打信用卡客服热线 400-889-5558 转人工办理。

**生效时间**：审批通过后实时生效。

## 固定额度提升

**办理条件**：开卡满 6 个月、用卡记录良好、近 3 个月有多元化消费。

**办理渠道**：与临时额度相同（APP / 微信公众号 / 客服热线）。

**审批时效**：1–3 个工作日，结果以短信通知。

## 额度下调（降额）

持卡人可主动申请下调固定额度，APP 额度管理页面提交或致电客服办理，实时生效，调低后的额度当日可用。

## 温馨提示

- 额度调整以银行最终审批结果为准；
- 临时额度到期后需一次性还清超出固定额度的部分；
- 渠道入口如有调整，以 APP 内实际页面为准。
