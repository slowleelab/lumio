# 境外交易锁定与解锁办理介绍

## 功能说明

境外锁开启后，卡片在境外线下刷卡、境外网站支付将被拒绝，境内交易不受影响。适合长期在境内用卡、防范境外盗刷的客户。

## 开启/关闭渠道

1. 「发卡银行 APP」→ 安全中心 → 交易管控 → 境外交易锁；
2. 微信公众号「发卡银行信用卡」→ 我的卡片 → 安全设置；
3. 拨打信用卡客服热线转人工办理。

**生效时间**：实时生效。

## 温馨提示

- 出境旅游/出差前，建议提前关闭境外锁；
- 锁定期间境外 ATM 取现同样被拒绝；
- 紧急情况可致电客服热线 24 小时处理。
