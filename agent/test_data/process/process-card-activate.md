# 信用卡激活与销卡办理介绍

## 新卡激活（开卡）

**办理条件**：本人收卡并核验卡面信息。

**办理渠道**：
1. 「发卡银行 APP」→ 我的 → 卡片激活；
2. 拨打卡面背面客服热线，按语音提示输入证件号与卡号后四位激活；
3. 微信公众号「发卡银行信用卡」→ 开卡激活。

**生效时间**：实时生效，激活后即可消费。

## 销卡/销户

**办理条件**：卡片无欠款、无溢缴款、无未完成的分期。

**办理渠道**：拨打信用卡客服热线转人工申请，或携身份证至网点办理。APP 销卡入口：我的 → 卡片管理 → 销卡登记。

**时效**：登记后 45 天为清账户期，期间不再使用卡片即正式销户。

## 温馨提示

- 销卡前请确认积分已使用或转赠，销户后积分清零；
- 附属卡随主卡一并销卡；
- 仅销卡不销户时，账户信息仍保留，可再次申请用卡。
