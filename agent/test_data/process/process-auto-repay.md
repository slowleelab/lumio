# 自动还款设置办理介绍

## 开通自动还款

**办理条件**：本人借记卡或他行储蓄卡（支持签约的银行），账户状态正常。

**还款方式**：
- 全额还款：到期还款日全额扣款，享免息；
- 最低还款：按最低还款额扣款，剩余部分计息。

**办理渠道**：
1. 「发卡银行 APP」→ 还款 → 自动还款设置；
2. 微信公众号「发卡银行信用卡」→ 还款 → 自动还款；
3. 拨打信用卡客服热线转人工办理。

**生效时间**：下一账单周期生效。

## 变更/取消

APP 自动还款页面可修改还款方式、扣款账户或关闭自动还款，到期还款日前一日 24 点前变更当期有效。

## 扣款顺序说明

到期还款日依次扣款：本行借记卡实时扣款；他行卡视清算时效 1–3 个工作日内扣款。请保证扣款日账户余额充足。
