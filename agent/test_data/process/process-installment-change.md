# 账单分期取消、结清与期数变更办理介绍

## 分期申请撤销

账单分期申请成功后、首期扣款前可撤销：APP → 分期理财 → 我的分期 → 撤销申请，实时生效，不产生手续费。

## 提前结清

**办理渠道**：APP 分期理财页面申请，或致电客服热线办理。

**费用说明**：剩余未摊销本金一次性计入下期账单，已收取的手续费不退，剩余未收取手续费按剩余本金的 3% 收取提前结清手续费。

## 期数变更

分期期数在办理成功后不可直接修改；如需调整，可对剩余分期申请提前结清后重新办理，或致电客服评估受理。

## 温馨提示

- 提前结清不改变已出账单的还款义务；
- 同一账单周期内撤销后可重新申请，每月限 2 次。
