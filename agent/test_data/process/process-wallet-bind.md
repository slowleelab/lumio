# 手机钱包绑定与解绑办理介绍

## 支持的钱包

Apple Pay、华为 Pay、小米 Pay、微信支付、支付宝。

## 绑定流程

**手机钱包（Apple Pay / 华为 Pay）**：
1. 打开系统钱包 APP → 添加银行卡；
2. 拍摄或手动输入卡号，验证预留手机号短信验证码；
3. 激活成功后即可挥手机支付。

**微信 / 支付宝**：
微信「我 → 服务 → 钱包 → 银行卡 → 添加银行卡」；支付宝「我的 → 银行卡 → 添加」，按提示完成短信验证。

## 解绑流程

在对应钱包 APP 内移除银行卡即可实时解绑；也可致电客服热线协助解绑。

## 温馨提示

- 绑定需验证预留手机号，换机/换号请先更新预留信息；
- 手机钱包支付受单笔/单日限额控制，可在 APP 安全中心调整；
- 手机丢失请立即致电客服挂失，钱包内卡片同步失效。
