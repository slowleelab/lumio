# 意图识别优化方案（问题总表 + 四阶段 + 进度）

> 版本：v1.0（2026-08-25）

## 结论

推理链路架构不用动（双通道 + 安全门已成熟，1805+ 测试背书）。优化集中在**数据/训练一致性、评测门规模、手工映射表、假开关、规则置信度、闭环通电**六个方向，按四阶段推进，扩类遵循「路由差异驱动、跟着下游能力走」。

## 四条贯穿原则

1. **路由差异驱动扩类**：同工具、同槽位、同转人工条件 → 不拆类。
2. **训练/推理分布一致**：教材只配「真正会到达分类器的分布」。
3. **输出信息增益分工**：零增益（精确问候/道别）→ 硬规则窄集；有增益 → 分类器。
4. **扩类跟着下游能力走**：工具/槽位 schema 配齐一批，扩一批。

## 明确不做

- 不重写分类器架构；不扩硬规则问候词表；不一次上 149 类；不自动重训/自动上线（人审保留）。
